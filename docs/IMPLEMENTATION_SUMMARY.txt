HOW TO USE:
================================================================================

For Admin (Creating Employees):
  1. Add Employee → Fill form
  2. Set password
  3. Click "Add Employee"
  4. ⏱️  WAIT 2-3 SECONDS
  5. Note password from success message
  6. Share credentials with employee

For Employee (Logging In):
  1. Go to /auth/login
  2. Enter email
  3. Enter password (exactly as provided)
  4. Click Login
  5. Should see salary dashboard

For Employee (Accessing Salary):
  1. Dashboard → Find salary slip
  2. Click "View" → See full preview
  3. Click "Download PDF" → Get PDF file
  4. Click "Download Word" → Get DOCX file
  5. Click "Print" → Print document

On Mobile:
  1. All layouts automatically adjust
  2. Buttons are full-width and easy to tap
  3. Text is readable
  4. No horizontal scrolling needed
